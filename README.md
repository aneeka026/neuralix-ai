# NEURALIX – AI Creative Platform
NEURALIX is a modern AI-powered creative platform designed to bring different AI creative tools into one workspace.
The project includes a complete responsive homepage with a futuristic UI, smooth animations, AI studio sections, model exploration, showcase gallery, pricing, and other supporting pages.

## Features

- Modern and responsive AI-focused homepage
- Hero section with Image, Video, Music and Voice options
- Interactive AI generation prompt UI
- Feature showcase with dynamic previews
- Multiple AI Studios with category filters
- AI model exploration section
- Showcase gallery with filters and preview modal
- Workflow section explaining the creation process
- Animated statistics with count-up effect
- AI Creative Agent interactive demo
- Pricing section with dynamic plan selection
- Login and Signup pages
- Responsive navigation with mobile menu
- Smooth animations and transitions
- Fully responsive design for different screen sizes

## Technologies Used

- React.js
- Vite
- Tailwind CSS
- Framer Motion
- React Router
- Lucide React Icons
- JavaScript (ES6+)
